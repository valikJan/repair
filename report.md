### 5. Фильтрация «мусора»

**10 нецелевых запросов:**
1. `скачать драйвер для ноутбука бесплатно` — информационно-дистрибуционный интент.
2. `как разобрать ноутбук своими руками` — DIY-интент.
3. `купить б у ноутбук на запчасти авито` — покупка б/у техники.
4. `вакансия мастер по ремонту ноутбуков новосибирск` — HR-интент.
5. `курсы по ремонту ноутбуков обучение` — образовательный интент.
6. `схема материнской платы ноутбука скачать pdf` — техническая документация.
7. `почему греется ноутбук в играх форумы` — информационный запрос.
8. `купить зарядное устройство для ноутбука днс` — товарный ритейл-запрос.
9. `видеоурок замена термопасты на ноутбуке` — обучающий видеоконтент.
10. `утилизация старых ноутбуков бесплатно` — нецелевая услуга.

**3 регулярных выражения:**
1. `^(?!.*(скачать|бесплатно|драйвер|инструкция|схема|pdf)).*$` — цель: отсечь поиск ПО и документации (дистрибуционный/информационный интент); эффект: снижение нецелевого трафика на 20–30%.
2. `^(?!.*(своими руками|самостоятельно|в домашних условиях|как разобрать|как починить)).*$` — цель: убрать самостоятельный ремонт (DIY-интент); эффект: рост конверсии (CR) посадочной страницы.
3. `^(?!.*(учебник|урок|видеоурок|курсы|обучение|вакансия|работа)).*$` — цель: исключить обучение и поиск вакансий (образовательный и HR-интент); эффект: чистое коммерческое ядро и экономия рекламного бюджета.

## Часть 2. Проверка `robots.txt` и чек-лист внутренней оптимизации

### Проверка `robots.txt`
1. **Расположение:** файл размещён в корне сайта (`https://novosib-laptop-fix.ru/robots.txt`).
2. **Синтаксис:** директивы `User-agent`, `Allow`, `Disallow`, `Sitemap` указаны без опечаток.
3. **Политика индексации:** основные страницы открыты (`Allow: /`), технические директории (`/admin/`, `/temp/`, `/cache/`) закрыты.

### Чек-лист «Проверка внутренней оптимизации»
* [x] **Валидность HTML5:** корректная структура `<!DOCTYPE html>` и семантические теги (`header`, `nav`, `main`, `section`, `article`, `footer`).
* [x] **Наличие `<h1>`:** единственный заголовок первого уровня на странице, строгая иерархия `h1 → h2 → h3`.
* [x] **Метаданные:** заполнены `<title>`, `meta description`, `meta keywords` и `canonical`.
* [x] **Файл `robots.txt`:** закрыты служебные разделы и указан путь к `sitemap.xml`.
* [x] **Файл `sitemap.xml`:** валидный XML со всеми 7 страницами сайта.
* [x] **Оптимизация изображений:** формат WebP, заданы `width`/`height`, `loading="lazy"`, `fetchpriority="high"`, информативные `alt` и `title`.
* [x] **Адаптивность:** относительные единицы `rem`, `em`, `%`, `clamp()` и CSS Grid.
* [x] **Доступность (A11y):** контраст текста WCAG AA, видимый `:focus-visible`, `aria-labelledby`, поддержка `prefers-reduced-motion`.
* [x] **Производительность:** системные шрифты, отсутствие блокирующих скриптов, `content-visibility: auto`.

### Пояснение и сравнение Microdata vs JSON-LD
* **Включённые свойства:** `PostalAddress`, `GeoCoordinates`, `areaServed` (привязка к Новосибирску и районам), `telephone` и `openingHoursSpecification` (контакты и график в сниппете), `OfferCatalog` / `Offer` / `Service` (услуги и минимальные цены в RUB), `FAQPage` (расширенный блок вопросов и ответов в выдаче).
* **Ограничения:** цены указаны с порогом «от», без рейтинга `AggregateRating` до сбора реальных отзывов.

| Критерий | Microdata | JSON-LD |
| :--- | :--- | :--- |
| **Внедрение** | Атрибуты (`itemscope`, `itemtype`, `itemprop`) внутри HTML-тегов. | Отдельный блок `<script type="application/ld+json">` в `<head>`. |
| **Поддержка кода** | Зависит от HTML-вёрстки; при редизайне легко сломать вложенность. | Не зависит от DOM и CSS-классов, легко обновлять. |
| **Сложные сущности** | Требует скрытых `<meta>` для массивов и координат. | Нативно поддерживает вложенные графы (`@graph`) и связи через `@id`. |
| **Поддержка ПС** | Яндекс и Google. | Рекомендованный формат Google; полностью поддерживается Яндексом. |
